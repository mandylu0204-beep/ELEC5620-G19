# A21：方案结果页展示

日期：2026-10-14。基于 A20 的 `3a1206f`，本轮仅调整前端展示。

## 完成内容

- 首屏显示实际营地名称、版本状态、确认日期与人数、已保存费用估算及安全评估。
- 行程、装备、费用、安全、记录分为五个标签；支持方向键、Home、End，隐藏标签内容不参与键盘访问。
- 超预算、证据质量问题与服务端阻止理由位于标签上方；安全依据入口定位安全标签。
- 行程采用时间线；费用保留整数 cents 显示及未知金额，已知小计单独展示；证据来源、有效日期、审核、输入指纹与模型记录仍可查看。
- 无匹配营地时保留最接近的三张对照卡片及手动调整需求入口。历史记录缺少对照摘要时提供原始排除理由入口。
- 保存后的方案使用同一布局，顶部保存记录栏压缩；历史保存记录明确提示其对应当时的方案。
- 桌面与窄屏适配；表格在自身容器内滚动。

后端、数据封存、共享 schema、数据库与保存/审核接口没有改动。用户动作仍使用原有修订、重评、审核及最终化入口和服务端可用标志。

## 本轮验证

使用三个独立临时 SQLite 实例，经真实登录、确认、HTTP 调度和浏览器读取。执行模式为 `deterministic_demo`，没有校园模型调用。本轮没有重跑全量后端测试，也不构成 Canvas 安装验收。

| 场景 | 结果 |
| --- | --- |
| 超预算修订 | Wattle Rest 估算 AUD 251 / 预算 AUD 245，展示差额 AUD 6，不能最终保存；浏览器提交低成本修订后 Moonlit Field 估算 AUD 231 / 余量 AUD 14，可勾选确认并保存。 |
| 同版本重评 | 浏览器提交重评，复用版本 2；产生新评估后再次保存。SQLite 为 3 runs、2 versions、6 assessments、2 final records；REVISE 与 REASSESS 关联同一版本 ID。 |
| 证据缺失与费用未知 | 在官方 missing_evidence 输入上另设交通距离未知，形成独立组合验证；天气缺失及费用未知均显示，已知小计 AUD 206 不作为总额，保存按钮禁用，最终记录为 0。 |
| 无匹配营地 | 官方 no_match 输入显示三张营地卡片、各自预算差额及调整建议。点击调整入口带回原预算 AUD 1 和两晚需求，未自动保存或确认；仍为 1 request、0 versions、0 final records。 |
| 可访问性与响应式 | 五个标签点击、方向键与 End 切换通过；390 像素视口下文档宽度与滚动宽度均为 375（扣除滚动条），没有页面横向溢出，装备表格在内部滚动。 |

类型检查及 Vite 生产构建通过（54 modules）；`git diff --check` 通过。构建第一次受 Windows 沙盒 `realpath EPERM` 限制，正常权限下复测通过。主场景、缺失证据场景的操作期间浏览器错误日志为空；不同端口测试实例共用同一主机 cookie，切换实例后重新登录，未将此会话切换误判为应用故障。
