# 用户可见的数据来源文案清理

基线：`main` / `82f2afe`。本轮未切分支，未重启服务，未调用校园模型。

## 排查结论

- 安全建议中的 `Synthetic data only; escalate to authorised Founder before use.` 来自模型保存的 `action_unverified`，不是固定前端文案。
- 另发现固定的交通费用/距离说明、旧请求错误、候选营地匹配说明、原始筛选理由、活动说明、风险原文、来源文件名和 PDF 导出提示可能出现同类字样。
- 模型和规则仍使用原始来源身份，展示处理不参与资料校验、安全结论、审核资格、最终保存或恢复。

## 修改范围

- 用户可见系统/模型文本去掉模拟、合成等来源限定语，保留实际风险、审核动作、费用估算、建议时间和未确认事项。
- 保存的筛选理由、历史活动、交通信息和折叠说明使用同一展示处理，不修改原模型产物、原始快照、来源文件、输入身份或摘要。
- 来源记录使用业务名称替代内部文件名；来源日期和覆盖日期保留。
- 诊断区仅显示可读摘要，保留模型身份、HTTP/token 用量和配置摘要哈希。来源类型、来源限定标记和完整来源身份映射不在摘要中展开，完整服务端审计仍保留。
- PDF 仅调整导出文案，保留预订、交通与安全需确认的说明。原始最终记录没有改写。
- 不对用户正在编辑的名称、需求及个人资料做通用替换。内部 API 元数据、源码中的兼容识别词和说明文件保留原始身份。
