# A22：资料、需求确认与规划入口

日期：2026-10-14。基于 A21 `f3bec97`；与 A21 一起交付。

## 展示与操作

- 三步指引连接资料填写、需求确认与开始规划。
- 资料页默认手动填写，演示样例为可展开入口；载入样例仍需用户核对并保存。
- 小组、交通、装备分区；数量、单位、每件人数容量及拥有确认分别展示。已有的单位值仍按原值传给后端。
- 小组人数、儿童人数冲突、数量、容量、装备名称和单位的错误在对应字段旁显示；保存入口说明无法提交的原因。未知的可选数量、容量和路程继续允许留空。
- 需求填写分为想法、目的地与行程、偏好与必须条件。保存草稿后生成摘要，再勾选确认并保存需求。
- 确认入口区分未生成摘要、待澄清、不支持、修改未保存及未勾选状态。澄清信息按字段分组，保留更具体的错误说明；“去补充”可展开可选字段并定位输入框。
- 日期、预算、资料摘要与可展开的完整资料供核对；修改后旧摘要及勾选不能沿用。
- 规划服务不可用时说明需求仍已保存；校园模式超过现有 30 晚限制时提示缩短行程并重新确认。

接口、服务端验证、CAS/CSRF/命令键、确认快照、规则及数据包均未修改。本轮只增加客户端提示、已有约束的即时校验与显示布局。

## 本轮验证

独立数据库 `var/a22-ui/demo.sqlite3`，`scripts/demo.py --case normal`，真实登录、浏览器操作、HTTP 调度及 SQLite 持久化，执行模式为 `deterministic_demo`。未调用校园模型，未修改个人配置及已有用户数据库。
