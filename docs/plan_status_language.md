# 方案状态与安全信息的用户文案

日期：2026-10-14。基于 A24 `319f541`。

方案列表只显示一个面向用户的结果，去掉执行状态/执行阶段重复拼接。“禁止放行”改为“方案有待完善”，无匹配结果明确显示未找到满足条件的营地，入口使用“查看方案/查看营地比较”。列表增加已保存行程日期；当前运行尚无绑定版本时不混入旧版本的状态。GET列表只读增量字段为search_outcome、start_date、end_date，不更改共享schema或写入接口。

详情显示“检查结果待更新”，解释保留行程重新检查装备、费用和安全，与修改日期/人数/预算后重新确认需求的区别。重复的底层错误移入系统详情；同一适用日期问题合并显示。导航按钮只展开既有操作区，不自动执行重评、修改需求或生成版本；重评按钮改为“保留行程，重新检查”，继续按服务端能力禁用。

安全页使用天气信息、营火规定、道路通行、营地规定。区分没有适用资料、已有资料待核实、日期不适用、资料过期及资料冲突。适用日期同时核对资料及来源范围。道路关闭即使资料已提供，仍显示关闭且使用问题色，不能误标为资料适用或等待批准即可解决。未知风险显示信息不足，普通用户主视图不显示置信度。

主视图给出具体问题和行动；原始英文建议、技术状态码、来源ID及完整风险/冲突/限制均保留在可展开详情。只对已知固定摘要做确定的中文展示，未知原文不猜测翻译。审核/最终化守卫、保存的评估结果、模型身份和数据包均未修改，不能通过文案变化解除限制。
